# FontCraft

Gestor de fuentes para macOS, Windows, Linux, Android e iPadOS: explora, previsualiza, imprime y activa fuentes,
con bibliotecas (`.fcl`), carpetas, listas inteligentes, Google Fonts y activación automática para las
apps de diseño.

- **Descargas:** en *Releases* (cada versión etiquetada `v…`).
- **Compilar:** a mano o con GitHub Actions; todo está en [`packaging/BUILD.md`](packaging/BUILD.md).
- **Cómo funciona por dentro:** [`MECHANICS.md`](MECHANICS.md).

Escrito en Rust (eframe/egui).
